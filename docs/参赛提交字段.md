## 作品简介（198 字 / 上限 200）

本作品是面向安全运营教学与攻防演练的 Web 安全平台。平台内置 5 条暴力破解检测规则，以滑动窗口与双指针算法覆盖高频失败、撞库、破解得手、字典与慢速破解；告警按风险分级，来源 IP 自动封禁 12 小时至 30 天，并在请求入口真实生效。DDoS 侧用内存状态机推演 6 类攻击，按平静、攀升、突袭、消退四阶段构造浪潮，攻击源取自固定肉鸡池；数据经 WebSocket 实时推送，以热力图、攻击链桑基图、可疑攻击源、受影响服务四重视角呈现，高危告警去重聚合后邮件推送值班人。全程不产生真实网络报文。

## 创意来源（273 字 / 上限 300）

传统安全教学缺少可复现、可调参、零法律风险的攻防演练环境：真实生产环境不敢调整检测阈值，也无法演示误报的代价。现有开源方案多偏重单一环节，或只做检测难有直观呈现，或只做大屏而缺少真实算法，难以同时用于课堂讲解与动手实验。由此设计本平台，将安全运营中心检测、告警、处置、复盘的全流程压缩为可现场操作的沙箱：登录日志为生成的模拟样本，但 5 条检测规则是真实算法，可原样对接真实认证日志；DDoS 侧以内存状态机推演 6 类攻击，按平静、攀升、突袭、消退四阶段构造攻击浪潮，呈现真实的事件型节奏；全部阈值集中在配置文件，可现场演示阈值与误报率的权衡。我们同时坚持数据透明：真实采集与沙箱模拟的数据在界面分别标注，不作混淆。

## 运行环境

```
操作系统：Windows 10/11（兼容 Linux）
语言与框架：Python 3.13 及以上；Flask（Web 框架）、Flask-SocketIO（实时通信）
关键依赖：eventlet、pandas、openpyxl、psutil（版本要求见 requirements.txt）
前端依赖：Bootstrap、ECharts、Socket.IO、jQuery，均已本地化部署
数据库：SQLite（零配置单文件，随程序自动创建并完成建表）
浏览器：Chrome 120 及以上（需支持 WebSocket 与 ES6）
外部服务：无需额外中间件或云服务；邮件通知需自行配置 SMTP 邮箱
运行方式：双击 start_demo.bat，自动创建数据库并启动服务，浏览器访问 http://127.0.0.1:5000，默认管理员 admin / Admin@123
运行说明：仅监听本机地址，可完全离线运行，全程不产生真实网络攻击流量
```
